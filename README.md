## 一、 项目简介

ViviBon Cover 是一个基于边缘计算架构的先锋宠物杂志封面生成工具。

系统面向精致养宠人群，免去注册登录与支付流程，用户上传日常宠物照片即可一键生成符合传统时尚杂志刊头规范（Bodoni 字体经典排版、苏富比双轨无墨凹凸压印钢印、1080×1440 纯艺术画幅）的高清艺术封面。

### 核心特性
* 零门槛即开即用：无须注册账号，无须绑定第三方登录，打开即用。
* 纯艺术交付：导出成片严格剔除任何营销二维码、商业网址及推广水印。
* 真实爱宠保真：仅采用纯图生图（Img2Img）多模态推理，锁定宠物面部特征，拒绝文生图随机漂移。
* 边缘极致性能：单页前端资源小于 100KB，首屏加载小于 100ms，依托全球边缘节点分发。

## 四、 系统核心设计原则

为保障服务稳定性、纯艺术质感与算力安全，系统强制执行以下核心约束：

| 序号 | 原则名称 | 核心工程实现 |
| :---: | :--- | :--- |
| 01 | 海报绝对纯净 | 导出成片仅渲染刊头、年份与艺术钢印，严禁夹带任何二维码与商业水印。 |
| 02 | 凭证绝对隔离 | 前端绝对不包含任何 API 密钥；密钥均加密存储于 Cloudflare Secrets。 |
| 03 | 算力成本熔断 | 边缘网关频控限制单 IP 每日 10 次；全网每日 1500 次调用即触发硬熔断。 |
| 04 | 超时降级自愈 | 请求硬超时设为 15 秒；上游异常毫秒级降级为预置样片，前端永不报错。 |
| 05 | 遥测非阻塞 | 接入数据埋点探针，埋点网络失败静默处理，绝不阻断用户核心操作。 |
| 06 | 防提示词注入 | 用户输入的宠物名仅供前端排版使用，严禁拼接至大模型推理提示词中。 |
| 07 | 前端体积预算 | 单页总文件严格限制在 100KB 左右，无需构建编译，保障首屏秒开。 |
| 08 | 避免重试惊群 | 异常重试引入随机全抖动（Full Jitter）与指数退避，防止流量雪崩。 |
| 09 | 爬虫防刷拦截 | 针对 curl、requests、自动化无头浏览器直接在边缘网关返回 403 阻断。 |
| 10 | 故障转移告警 | 主模型失败自动切备用模型，并毫秒级向企业微信派发根因诊断卡片。 |
| 11 | 内容安全规范 | 输入敏感词正则过滤；提示词强制注入高光防灰阶约束，排斥违规内容。 |
| 12 | 移动内存防暴死 | 选图离屏采样缩减 90% 显存防闪退；成片叠加透明原生图片保障长按保存。 |
| 13 | 体验情绪抚慰 | 15 秒等待期采用暗室显影仪式替代枯燥进度条；后台切回自动状态校准。 |

## 五、 关键技术亮点

### 1. 0-RTT 网络预热与离屏图像采样
* 在用户调起手机系统相册选图时，前端静默向边缘网关发送轻量保活探针，提前激活移动基带与 TCP/TLS 连接通道，实现点击生成时零延迟握手。
* 图像在客户端通过独立 Web Worker 离屏进行 16 步进硬件对齐采样（768×1024），使上传体积缩小 72% 至约 55KB，同时处理完毕后强制释放画布显存，根除移动端内存溢出闪退。

### 2. 多轨图生图调度与优雅降级
* 服务端以 302.ai（Gemini 3.1 Flash Lite）作为图生图主力，辅以火山引擎豆包等国内备选轨；
* 全链路配置 15 秒硬超时中断保护；一旦遇到网络波动或上游欠费，系统毫秒级自愈降级至本地高定标杆成片，保证用户端永远流畅无白屏。

### 3. 多感官微交互与无墨压印排版
* 交互体验融入 3D 柱面纸张翻卷、欧拉飞轮惯性滑动及暗室同心微波显影；
* 配合纯原生算法合成的机械快门声学总线与微脉冲触感；
* 结果页搭载陀螺仪微视差浮动，导出端基于 Canvas 像素偏移绘制纯正的苏富比双轨无墨凹凸防伪钢印。

## 八、 生产部署与配置

### 1. 生产环境部署指令
```bash
# 1. 部署前端至 Cloudflare Pages
npx wrangler pages deploy public --project-name=vivibon-cover --branch=main

# 2. 部署后端至 Cloudflare Workers
cd worker
node build.js
npx wrangler deploy
```

### 2. 生产密钥配置项说明
后端运行依赖以下环境变量（通过 Cloudflare 控制台或 wrangler secret 安全注入，切勿提交到代码库）：
* `AI302_API_KEY`：302.ai 生产环境 API 密钥；
* `VOLCENGINE_API_KEY`：火山引擎 API 密钥；
* `WECHAT_WEBHOOK_URL`：企业微信告警机器人 Webhook 地址；
* `RATE_LIMIT_KV`：Cloudflare KV 频控命名空间绑定 ID。
